# JANA2 attribute vocabulary — for the SECOND pass, after an object is named.
#
# Format:
#   [group_name] applies_to=person,man,woman
#   full descriptive phrase
#   ...
#
# Two rules that matter:
#  1. Groups are mutually exclusive, so scores are softmaxed WITHIN a group.
#     "upper_colour" gives one answer, not five.
#  2. Phrases, not bare adjectives. CLIP scores "a person wearing a red shirt"
#     far more reliably than "red". Never put bare "red" in here.
#
# If the top score in a group is not clearly ahead of the second, the caption
# must omit that attribute entirely. Guessing a shirt colour in a crime report
# is worse than saying nothing.
