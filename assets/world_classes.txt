# Classes handed to YOLO-World as text queries.
# Purpose: Indian video surveillance — roads, housing societies, mall
# entries and exits. Crime and incident detection.
#
# Every line here must earn its place. Open-vocabulary detection gets WORSE
# as the list grows, and near-synonyms split the score between them. If a
# class would never change what an operator does, delete it.
#
# Deliberately NOT here: furniture, kitchenware, office supplies, plants,
# scenery. They are detectable but they are never the reason anyone opens
# the footage.
